# primes

Find all prime numbers up to N using the Sieve of Eratosthenes.

## Usage

```
python primes.py [N]
```

`N` defaults to 100. Example:

```
python primes.py 1000
```

Prints the count of primes up to N followed by the primes themselves.
Fast enough for N up to ~10,000,000 (fractions of a second).
